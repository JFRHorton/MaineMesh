General guidelines for naming shared resources.
If possible, add mainemesh.org to core infrastructure node names, to direct new users to our group.

| Role       | Prefix             | Short Name Example | Long Name Example                | Description                         |
|------------|--------------------|--------------------|----------------------------------|-------------------------------------|
| Router     | MR                 | MR1                | MR1_Portland_West | Primary mesh routing node                          |
| Link       | ML                 | ML1                | ML1_Portland_West | Fill-in nodes between routers                      |
| Sensor     | MS                 | MS1                | MS1_Portland_West | Weather or environmental telemetry                 |
| Gateway    | MG                 | MG1                | MG1_Portland_West | Administrative bridge                              |
